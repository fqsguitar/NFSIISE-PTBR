# Need for Speed II Special Edition — Tradução PT-BR 🇧🇷

> **Tradução brasileira de Need for Speed II Special Edition (1997).** Reviva esse clássico das corridas em PT-BR, com menus traduzidos, arquivos editáveis e gerador de tradução!

Tradução comunitária para português brasileiro de Need for Speed II Special Edition (PC).

## Instalação

1. Faça backup do `text.eng` original na pasta do `nfs2se.exe`.
2. Copie o `text.eng` traduzido para essa mesma pasta.
3. Inicie o jogo normalmente.

**Importante:** o português substitui o inglês; ainda não é um sétimo idioma.

## Personalização

O arquivo `NFSIISE_PTBR.csv` contém 1.502 entradas. Edite apenas a coluna `traducao_ptbr_proposta` e execute `GERAR_TEXT_ENG.bat` no Windows para gerar outro `text.eng`.
